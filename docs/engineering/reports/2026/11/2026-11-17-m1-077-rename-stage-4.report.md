## Implicit state review

1. **Demo form found by title.** The seed looks the demo form up by its title. Renaming it would
   have made every seeded database (local, OCI) get a second form at the next seed. The title names
   the company and stays, so this state is not touched.
2. **Labels in open editor sessions.** The admin UI loads labels at page load; an editor with it open
   during the release sees old labels until a reload. No data effect; noted in the handoff.
3. **Seeded PDF copies.** Stored attachments keep the old producer string; the seed finds the
   existing file piece by title and does not upload again. No user effect; recorded.
4. **Test tooling vs a second server** (found while testing): `test:forms` tasks follow `.env`, not
   the server under test. Recorded in design §10 and the m1-078 handoff, so the next agent sets
   `APOS_DB_URI` too. Changing the suite was out of scope.

No new state is added.
