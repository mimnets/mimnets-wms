## Implicit state review

1. **Renewal hook name on the `certs` volume** lives longer than any image. Decision: both names in
   the certbot image until stage 5 (Q1 a); tested by name. Stage 5 can drop the link after the
   renewal files are rewritten or certificates reissued.
2. **TLS-serial marker** compared by `deploy.sh` across two releases: the first deploy forward or
   back restarts MongoDB and its clients once more. Accepted and documented (runbook §12.4) instead
   of code that reads both names.
3. **Image name per service** changes once, so Compose recreates every service, MongoDB included:
   documented, with the timing decision Q4.
4. **App user** keeps uid 1001 and gid 999, so files on the existing volumes stay readable.
   `setup.sh` sets ownership by number.
5. **ghcr.io packages**: new ones private by default; old ones kept for rollback (Q3).
6. **Server pull token**: must read the new packages; `deploy.sh` stops before any change if not.
